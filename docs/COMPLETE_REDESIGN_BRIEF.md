# SahlDZ V4 — Complete Interface Replacement

## القرار

ابنِ واجهة الويب الإدارية من جديد فوق نظام SahlDZ القائم. لا تحسّن التصميم الموجود، ولا تعالجه على أنه مرجع. احتفظ بالوظائف والبيانات والصلاحيات والمسارات فقط؛ كل ما يراه المستخدم من هيكل وتوزيع ومكوّنات عرض يعاد تأليفه.

## المفهوم

**Restaurant Control Desk**: مكتب تحكم يومي للمدير العام. بدلاً من لوحة مؤشرات تقليدية، يفتح المدير مساحة عمل تبدأ بما يلزم اتخاذ قرار بشأنه، ثم تعرض ملخص الأداء والسجل الذي يثبت ما حدث.

## الاختلاف الإلزامي عن النسخة السابقة

| التصميم المستبدل | التصميم الجديد |
| --- | --- |
| شريط جانبي دائم | شريط أوامر علوي + شريط وحدات أفقي/قائمة وحدات |
| صف KPI أو شبكة بطاقات | موجز أداء متصل داخل منطقة عمل |
| بانر تنزيل تطبيق | لا محتوى ترويجي في لوحة المدير |
| مساحة سفلية فارغة | سجل نشاط أو حالة فارغة تقود إلى فعل |
| بطاقات متكررة | مناطق عمل ذات وظائف مختلفة: طابور، موجز، سجل |
| صفحة كلها wrappers | قالب صفحة عمل كامل: سياق، أدوات، محتوى |

## صفحة `/ops` الجديدة

1. **Command bar:** مطعم/فرع، بحث، فترة، إشعارات، حساب.
2. **Module bar:** تنقل أفقي للوحدات، منظم في المجموعات المعتمدة، مع وصول إلى كل روابط النظام القائمة.
3. **Work Queue:** المنطقة الأولى بصريًا. تعرض المشاكل/الإجراءات الحقيقية الحالية، وتوصل إلى مكان تنفيذ الإجراء.
4. **Performance Brief:** قراءة واحدة مترابطة للإيراد والمصاريف والربح والهدر أو أي مؤشر حقيقي متاح؛ ليست بطاقات مستقلة.
5. **Recent Activity:** سجل معاملات أو عمليات حديثة، أو empty state تشرح الخطوة التالية عند غياب البيانات.

## حدود التنفيذ

- استبدل DOM وlayout صفحة المدير. لا تُعد استخدام markup البطاقات أو layout القديم.
- لا تغير Supabase، Firebase، server functions، auth، permissions، routes، الحسابات، أو منطق CRUD.
- لا تلمس landing، cashier، kitchen، waiter، mobile، QR، Electron، أو kiosk.
- لا تضف package أو بيانات وهمية.
- لا AI visuals، gradients، glass، glow، floating buttons، أو زخرفة لا تخدم قرارًا أو فعلًا.

## اختبار القبول البصري

قبل التسليم، قارن لقطة `/ops` حديثة بلقطة التصميم السابق. يجب أن تكون الإجابة على الأسئلة التالية «نعم»:

1. هل اختفى الشريط الجانبي الدائم تمامًا؟
2. هل اختفت شبكة KPI/البطاقات المتساوية تمامًا؟
3. هل اختفى بانر تنزيل التطبيق والمساعد العائم؟
4. هل الصفحة منظمة كطابور عمل + موجز أداء + سجل، لا كـ dashboard تقليدي؟
5. هل ما زال كل سلوك النظام يعمل؟
